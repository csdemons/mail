# Atom Workspace

Рабочее пространство для сотрудников НИЦ «Курчатовский институт» (прежнее название — Atom Mail):
почта, календарь, контакты, задачи, чат и файлы в одной программе. Работает в **Windows**, **Linux** (в том числе
Astra Linux SE 1.7 и 1.8) и **macOS**.

Программа работает напрямую с серверами организации — IMAP/SMTP, Exchange (EWS),
CalDAV/CardDAV, Nextcloud — без промежуточного сервера: как Outlook или Thunderbird.
Стек: [Tauri 2](https://tauri.app) (Rust) + React + TypeScript; для Astra 1.7 — та же
программа на Tauri 1.

Программа обновляется сама: проверяет новую версию при запуске и раз в 6 часов. Обновления
подписаны (Ed25519, SHA-256 каждого пакета); администратор может отключить проверку или
направить её на внутреннее зеркало — см. [руководство администратора](docs/admin-guide.md#обновления).

## Возможности

**Учётные записи**
- Вход по адресу и паролю — серверы определяются сами (известные службы, autoconfig, пробное подключение к imap./mail. домена);
  можно указать вручную.
- **Exchange 2013/2016/2019/SE** через EWS: Autodiscover, вход Windows (NTLMv2 с привязкой
  к TLS-каналу, как у Outlook) или Basic по HTTPS; почта, календарь, контакты, адресная книга
  организации. Встроенная диагностика входа.
- Несколько учётных записей, «Все входящие» и общие папки всех ящиков, переключение без
  потери места, где вы были.
- Пароль — только в системном хранилище (Диспетчер учётных данных Windows, GNOME Keyring /
  KWallet, Связка ключей macOS). Защита программы кодом из приложения (TOTP).

**Почта**
- Папки (вложенные, кириллица), постраничный список, цепочки писем, HTML-письма с оформлением
  в изолированной рамке, внешние картинки — только по кнопке, предупреждение о фишинговых ссылках.
- Редактор с оформлением, подписью, шаблонами, проверкой орфографии; отмена и отложенная
  отправка, уведомление о прочтении, «Отложить письмо».
- Флажки со сроком, цветные категории, «Это спам», отписка от рассылок, печать и PDF.
- **Поиск** по всем папкам и ящикам (на компьютере и на сервере), сохранённые поиски.
- **Правила обработки почты**: серверные (SOGo/Sieve) и правила программы — папка, категория,
  уведомление, задача в Deck.
- Вложения открываются в программе (картинки, PDF, текст) или щелчком — в программе компьютера
  (Word, Excel, LibreOffice — копия с пометкой «из интернета»), перетаскиваются в папки
  компьютера и из них; пересылка с вложениями; файл календаря (.ics) из письма — сразу в календарь.
- **Работа без сети**: письма и папки с компьютера, очередь действий и исходящих, выполнение
  по порядку при подключении, разбор конфликтов.
- **Контрагенты**: вся история работы с организацией — переписка, документы, встречи, люди,
  договорённости.
- Перенос почты из Outlook (.pst) и Thunderbird, контакты из vCard/CSV, резервная копия в .mbox.

**Календарь и контакты** (CalDAV/CardDAV, SOGo, Exchange)
- Неделя, повторяющиеся события, весь день, часовые пояса, несколько календарей; создание,
  перенос, изменение, удаление.
- Контакты и корпоративная адресная книга, подсказки адресов при написании письма.

**Nextcloud**
- **Задачи** (Deck): доски, колонки, карточки, перетаскивание, сроки, исполнители.
- **Чат** (Talk): беседы, «Избранное» (закреплённые сверху), отметки ✓/✓✓ о прочтении, упоминания,
  реакции, файлы, ответы с цитатой, недописанное сообщение сохраняется.
- **Файлы**: облачный диск, общий доступ и «Отправить ссылкой», редактирование документов.

**Окно и система**: тёмная тема, трей со счётчиком непрочитанных, системные уведомления
(содержимое — по политике администратора), автозапуск.

## Безопасность

Письма на компьютере хранятся зашифрованными (ключ — в системном хранилище), HTML очищается и
показывается без скриптов, сертификаты серверов проверяются системным хранилищем, обновления
подписаны. Администратор управляет поведением через `policy.json` или групповую политику.
Подробно — в [SECURITY.md](SECURITY.md); последние исправления по аудиту — в
[CHANGELOG.md](CHANGELOG.md) (0.30.3).

## Разработка

```bash
npm install          # зависимости, в том числе frontend
npm run dev          # окно приложения с hot reload
npm run build        # установщики в src-tauri/target/release/bundle/
```

Системные пакеты, структура кода, тесты (юнит, E2E против тестовых серверов) и выпуск
версии — в [docs/development.md](docs/development.md).

## План

- Exchange: приглашения участникам и ответы на них, шаблоны, «Отложить», отложенная отправка.

- Клиент для Android (на общем ядре).
